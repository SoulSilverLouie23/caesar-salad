# caesar-salad

A tiny browser app that helps you design a **no-investment micro-SaaS / digital product offer** and estimate realistic monthly revenue targets.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## What it does

- Lets you pick a niche, skill, and available weekly hours.
- Generates an app concept + monetization model.
- Calculates how many low-ticket or high-ticket sales are needed to hit a monthly target.
- Provides a simple launch checklist.
